# ADR NNNN: Short decision title

Status: Proposed

## Context

What problem or constraint requires a decision? Link relevant code, product
requirements, and verified evidence. Do not include personal/private content.

## Decision

State the proposed choice and its boundaries. Identify defaults, limits,
failure/recovery behavior, and any scope change needing approval.

## Alternatives considered

Explain the meaningful alternatives and why each was not selected.

## Consequences

Describe benefits, tradeoffs, privacy/accessibility/operational impact,
compatibility/migration needs, and what remains out of scope.

## Evidence and verification

Record how the choice was confirmed before changing status to Accepted.
List focused acceptance cases and relevant test surfaces.

## Supersedes / related decisions

Link related ADRs. If replacing an accepted decision, mark it Superseded and
link both records. Delete this paragraph if it does not apply.
